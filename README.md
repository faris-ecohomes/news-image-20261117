One bold front-page poster that sums up the world news of Monday 17 November 2026 in a single 1024x1024 image: Trump, Xi and Putin set for a first three-way summit in Shenzhen, Ukraine striking the Kerch Bridge while Russia answers with a ballistic attack on Kyiv, Iranian drones hitting a US radar site in Bahrain for a third time in days, Washington tightening AI chip export rules on China, the Quad unveiling critical-minerals and defence pacts in Manila, and the WHO confirming Eritrea has eliminated trachoma. The poster is drawn programmatically with Python and Pillow by `make_image.py` (vector icons and type only, no photographs); `main.py` copies the finished `entry.png` to the output directory byte for byte.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
